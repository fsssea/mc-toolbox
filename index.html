1.0.0 回顾 / 已包含在 1.1.0

1.0.0 打下的底子。

不是把按钮堆满首页。1.0.0 只做三件事：把存档核心数据翻成人能读的代码、让长字段在手机上自己折行、让 db 里的文件也能按字节改。

CODEX / 英文代码

level.dat，直接翻成英文代码

一行一个字段：类型 路径 = 值。世界名、随机种子、难度、生成器类型、游戏规则、实验开关，全部明文呈现。

  • 改完点「保存到存档」，自动编码回二进制 NBT
  • 写回前先自动备份，改错可回退
  • 手机端与桌面端同一套逻辑
WRAP / 自动换行

长字段自己折行，手机不用横拖

很长的世界名、成串的 byte 数组，按窗口宽度自动折行；横向滚动关掉，打开就是第一行。

  • 折行只影响显示，不动保存逻辑
  • 渲染完滚动条归零，不用找开头
  • 手机竖屏也能整段读完
DB / 文件级编辑

db 里的文件，也能逐个改

不是 NBT 的文件按 0x 偏移列出英文串，引号里的内容可就地替换；也能按十进制字节编辑，大文件 4KB 分页。

  • 保存前自动备份整包
  • 界面常驻提示：db 是存档最重要的数据文件夹
  • 随便修改可能导致存档报废，先导出再改

README / 使用说明

装之前，先看这四条。

尤其是第三条。db 是存档里最要紧的地方，改之前请先导出备份。

三端装哪个？能一起装吗？

按设备选：手机装 APK，Windows 解压 ZIP 直接用，Linux 用 tar.gz 或 deb，不想装东西就开网页版（1.1.0，保留地形层转换）。三端是不同设备上的同一款软件，包名与桌面端不冲突；同一台手机重复覆盖安装即可升级。

英文代码改完，存档会不会坏？

只改等号右边的值，左边的类型与路径不要动。点「保存到存档」时会先自动备份整包，再重新编码成二进制 NBT 写回；写坏了可以用备份回退。

db 文件夹能随便改吗？

不能。db 是存档最重要的数据文件夹，随便修改可能导致存档报废。界面会一直提示这一点；动手前请先用「导出存档」备份一份，只改你确定要改的字段。

需要联网吗？开源吗？

全离线运行，不联网也能用，不上传任何存档数据。代码 MIT 开源，仓库地址 github.com/fsssea/mc-toolbox。
